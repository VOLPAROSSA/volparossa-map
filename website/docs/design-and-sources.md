# The Mountain Passes

The composition follows the supplied Concept 2, preserved in [the original reference](../masters/design-reference.png). Desktop and mobile hero and hut scenes have independent compositions. The other panoramic strips retain their source picture planes. A right-hand sunset crop keeps the fox, compass and trail marker together on mobile. The mobile terrace uses a separate clear table so both private screens can use larger type.

The landscape masters were generated for VOLPAROSSA from the supplied design. [Generation descriptions](../masters/generation.json) identify each scene. Width, height and digest of each raster export are recorded in the [inventory](../asset-manifest.json). To maintain the raster derivatives, use `scripts/export_images.py` with Pillow and AVIF/WebP support. The social card is a 1200 × 630 browser capture of `masters/social.html`. These maintainer operations are independent of the static build.

The offline region is original, fictional cartography. Its reproducible source, [draw_region.py](../scripts/draw_region.py), draws relief, contour isolines, river, lake, trails, bridge, mountain hut and place labels as separate layers. Regeneration uses NumPy, contourpy and Pillow. The page loads the finished SVG locally. Every map extract uses this same region. No real tracks, coordinates, commercial tiles or compiled Organic Maps regions were used.

The [unmodified upstream Organic Maps mark](https://organicmaps.app/logos/green-on-white.svg) was retrieved on 18 November 2026 and is displayed next to the upstream link. The [Map provenance notes](https://github.com/VOLPAROSSA/volparossa-map/blob/95a83c2869858aa90d04b60bf0bca63274397520/docs/UPSTREAM.md) distinguish branding, source licences and compiled data terms. The credits also link to [OpenStreetMap](https://www.openstreetmap.org/copyright). Local [Lucide symbols](../masters/icons/) come from the correspondingly named files in [the pinned Lucide icons directory](https://github.com/lucide-icons/lucide/tree/a630cec77eac6568b989e87e4947a8bfe45caacd/icons). Their licence is shipped under assets/upstream. The gold mark, fonts, GitHub Octicon and their notices came from the original central theme export.

Product claims were compared with Map main at `95a83c2869858aa90d04b60bf0bca63274397520`. The [traffic adapter](https://github.com/VOLPAROSSA/volparossa-map/blob/95a83c2869858aa90d04b60bf0bca63274397520/docs/TRAFFIC_ADAPTER.md) validates bounded snapshots. The [accepted Android checkpoint](https://github.com/VOLPAROSSA/volparossa-map/blob/95a83c2869858aa90d04b60bf0bca63274397520/docs/DPS_INTEGRATION.md#accepted-bounded-synthetic-debug-activityjni-checkpoint) exercised eight synthetic JNI cases in a debug activity. Its physical sensor, accuracy, host-comparison and navigation limitations remain documented there. The visitor-facing examples are static, with no sensor request, map download, prompt submission or application runtime.
