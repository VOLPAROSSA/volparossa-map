Map illustrations and credits

Alpine landscapes

The scenes were generated for VOLPAROSSA from the owner-supplied Mountain Passes design. The valley, trail names, topographic relief and observations are fictional. The illustrations use original drawn routes and interface elements.

Organic Maps

The original green-on-white mark identifies the upstream Organic Maps Project. VOLPAROSSA is developing an independent integration. Organic Maps code, trademarks and compiled map data have separate terms.

Organic Maps Project · Original mark · Source and data notices

Organic Maps uses OpenStreetMap data. The illustrations on this website were drawn from synthetic terrain. OpenStreetMap attribution and licence.

Type and icons

Cormorant Garamond, Inter and the original gold emblem come from the shared VOLPAROSSA website theme. The interface uses Lucide icons and the GitHub Octicon. Lucide licence · Octicons licence · Theme sources.
